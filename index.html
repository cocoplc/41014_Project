UR3 Vision-Guided Pick in MuJoCo

Chloe Sargiss, Hannah Murphy, Angus Tedeschi, Josephine Thu
41014 Sensors and Control for Mechatronic Systems – Assessment 4 Integrated Project (Track B) University of Technology Sydney
Code Results Evidence

A UR3 locates a randomly placed ball with its wrist RGB-D camera, then moves in and picks it up.

Overview

This project builds a full sense–estimate–control loop for a UR3 manipulator in MuJoCo. A ball is placed at a random position on a table. The robot moves to a look pose, uses a wrist-mounted RGB-D camera to localise the ball, estimates its joint state with a Kalman filter, and uses visual servoing and planning to reach and grasp it.

The system brings together the main topics of 41014: sensor modelling, state-space control, state estimation and vision-based control.

System Pipeline

  1. Scene setup – UR3, table, gripper, wrist camera and a randomly positioned ball in MuJoCo.
  2. RGB-D vision – the camera image and depth are used to find the ball and convert it to a 3D position.
  3. State estimation – a Kalman filter estimates the robot's joint states from noisy measurements.
  4. Control and planning – state-space control and visual servoing move the gripper to the ball.
  5. Grasp – the gripper closes gradually and holds the ball.

Simulation Scene

The robot starts from a fixed look pose so the ball is in the camera's view. Each run resets the scene with a new random ball position.

Vision Localisation

The wrist camera's RGB and depth images are combined to find the ball's position relative to the robot.

Results

Vision localisation was evaluated across multiple random ball positions by comparing the estimated position against the ground truth from the simulator.

cd A4_SC
pip install mujoco numpy opencv-python matplotlib

python scene_setup.py        # scene with look pose and random ball
python Josie_snp.py          # full pick
python evaluate_vision.py    # vision localisation evaluation
